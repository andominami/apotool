# apotool — 保険算定ルール検索サイト

歯科の保険算定・カルテ入力で間違いやすいルールをキーワードで検索できる社内リファレンスサイトです。
これまでエクセルで管理していた「保険算定ルール一覧」をもとに作成しています。

## 見る

`site/index.html` をブラウザで開くだけで動きます（サーバー不要・ログイン不要）。

- キーワード検索（スペース区切りでAND検索、タイトル・本文・カテゴリを横断）
- カテゴリでの絞り込み
- 「返戻」「査定」「指導」など注意ワードの自動ハイライト
- 新しい順 / 古い順の切り替え

## 内容を更新する

### まとめて更新する場合（エクセルを直したとき）

1. エクセル（シート名「保険算定ルール一覧」、列: `No / 日付 / カテゴリ / タイトル / 内容(ルール詳細) / 添付画像`）を更新する
2. 依存パッケージを入れる（初回のみ）
   ```
   pip install -r requirements.txt
   ```
3. サイトを再生成する
   ```
   python3 scripts/build_site.py <更新したエクセルのパス>
   ```
   `data/insurance_rules.json` と `site/index.html` が最新の内容で書き出されます。
4. 変更をコミット・プッシュする

### 1件だけ追加する場合（Teams等での新しい投稿）

Teams に上司から新しい投稿があったときは、エクセル全体を作り直さなくても1件だけ追加できる。

```
python3 scripts/add_entry.py \
  --date 2026/08/28 \
  --category "カテゴリ名" \
  --title "タイトル" \
  --content "本文"
```

`data/insurance_rules.json` に追記され、`site/index.html` も自動で再生成される。

現状の運用: Teamsへの投稿内容をコピペで Claude に渡してもらえれば、上記の追加とサイトの再公開まで対応する。

見た目やレイアウトを変えたい場合は `site/template.html` を編集してから、同じ手順で `build_site.py` を実行してください（`site/index.html` は自動生成ファイルなので直接編集しても次回の再生成で上書きされます）。

## 公開方法について

このリポジトリは非公開（private）です。サイトとして社内に共有する方法はいくつか選べます。

- **このまま `site/index.html` を配る** — ファイルをそのまま開けば動くので、共有フォルダに置く／メールで送るだけでも使えます
- **GitHub Pages** — 同じリポジトリから自動公開できますが、private リポジトリで Pages を使うには GitHub の有料プラン（Pro/Team/Enterprise）が必要です
- **Claude のプロトタイプ URL を使い続ける** — アップデートのたびに `site/index.html` の内容を反映して同じ URL に再公開できます（ログイン不要ですぐ使える）

どの方法にするか決まっていない場合は、まず現状の Claude 側の URL を使いながら、必要になったタイミングで GitHub Pages 等の正式な公開先を検討するのがおすすめです。

## ディレクトリ構成

```
data/insurance_rules.json   … 抽出したルールデータ(JSON)
site/template.html          … サイトのテンプレート(データ部分はプレースホルダ)
site/index.html             … 生成済みのサイト本体(そのまま開ける)
scripts/build_site.py       … エクセル → JSON / サイト の変換スクリプト
```

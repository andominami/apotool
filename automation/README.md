# Googleフォームからの自動投稿セットアップ

スタッフがGoogleフォームに投稿すると、自動でこのサイト（`data/rules.json`）に
追加され、GitHub Pagesへ公開されます。

## 全体の流れ

```
Googleフォーム回答
   → 連携するGoogleスプレッドシートに自動で行が追加される
   → スプレッドシートの Apps Script が「フォーム送信時」に自動起動
   → GitHub API 経由で data/rules.json（と写真）を更新
   → GitHub Pages が自動で再デプロイ
```

## 1. GitHubのアクセストークンを発行する

1. GitHubで自分のアイコン → **Settings → Developer settings → Personal access tokens
   → Fine-grained tokens** を開く
2. **Generate new token**
   - Repository access: **Only select repositories** → `tanpopo` を選択
   - Permissions → **Contents** を **Read and write** に設定
   - 有効期限はお好みで（更新の手間を減らすなら長め、セキュリティ重視なら短め）
3. 発行されたトークン（`github_pat_...`）をコピーしておく
   （**このページを閉じると二度と表示されません**。安全な場所に一時保存してください）

## 2. Googleフォームを作る

以下の質問を作成する（表記はこのままでOK、順番は自由）。

| 質問 | 種類 | 必須 |
|---|---|---|
| タイトル | 記述式 | ✅ |
| カテゴリ | プルダウン（下記の10種類） | ✅ |
| 内容・詳細 | 段落 | ✅ |
| 投稿者名 | 記述式 | 任意 |
| 写真 | ファイルのアップロード | 任意 |

カテゴリのプルダウンの選択肢（サイトのサイドバーと合わせる）:

```
歯周病治療
カルテ入力
レントゲン撮影
口腔機能発達不全症
歯科技工
制度改定
レセプト・カルテ
健診
文書
その他
```

「ファイルのアップロード」を使う場合、フォームの設定でその質問には
回答者がGoogleアカウントでログインしている必要がある旨が表示されます
（院内のGoogleアカウントで運用する分には問題ありません）。

なお、アップロードされた写真はGoogleフォームの仕様上、投稿者のマイドライブに
一旦保存されます。Apps ScriptがGitHubへコピーした後、マイドライブの容量を
圧迫しないようドライブ側のファイルは自動で完全に削除する仕様にしています
（サイトが表示する画像はGitHub上のコピーのみ）。
※Googleフォームが自動作成するこの「ファイルの回答」フォルダは、仕様上
共有ドライブへ移動することができません(試すとエラーにはならず候補にも
出てこない場合があります)。容量を個人のマイドライブではなく共有ドライブ側で
持たせたい場合は、この自動削除の仕組みは使わず別途対応が必要です。

## 3. スプレッドシートと連携する

フォームの「回答」タブ → 緑色のスプレッドシートアイコン →
「新しいスプレッドシートを作成」で連携する。

## 4. Apps Scriptを設定する

1. 連携したスプレッドシートを開く → メニューの **拡張機能 → Apps Script**
2. デフォルトの `Code.gs` の中身を全部消して、このリポジトリの
   `automation/google-form-to-github.gs` の中身を貼り付ける
3. 左側の歯車アイコン「プロジェクトの設定」→ 一番下「スクリプト プロパティ」で
   以下を追加する（**コードには直接書かない**）

   | プロパティ | 値 |
   |---|---|
   | `GITHUB_TOKEN` | 手順1で発行したトークン |
   | `REPO_OWNER` | `andominami` |
   | `REPO_NAME` | `tanpopo` |

4. 上部の「時計」アイコン（トリガー）→ **トリガーを追加**
   - 実行する関数: `onFormSubmit`
   - イベントのソース: `スプレッドシートから`
   - イベントの種類: `フォーム送信時`
   - 保存時にGoogleアカウントの権限承認を求められるので許可する

## 5. テストする

実際にフォームから1件テスト投稿してみて、数分後に
https://andominami.github.io/tanpopo/ に反映されているか確認する。

うまく反映されない場合は、Apps Scriptエディタの左側「実行数」から
エラーログを確認できます（GitHubトークンの権限不足、質問名の表記ゆれ等が
よくある原因です）。
